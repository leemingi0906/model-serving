발전 실적 데이터 업로드

data/uploads/는 여기서 업로드한 CSV만 쌓이는 곳입니다. 학습(train_and_register.py 등)은 항상 가장 최근에 올라온 파일을 사용합니다. data/sample_solar_hourly.csv.gz(발전소 10곳 시간별 실적 2023-01~2026-08)를 올려보세요 (컬럼: plant_id, time, generation_kwh · .csv 또는 .csv.gz). 기상(관측·예보)과 발전소 레지스트리는 서버에 동봉되어 있습니다.

다음 날 24시간 발전량 예측

발전소와 예측일(D)을 고르면 업로드된 실적에서 D-3~D-1 72시간 이력을, 서버에 동봉된 하루 전 예보(일사·운량·기온)를 가져와 POST /predict로 D일 01~24시 발전량을 예측합니다(실제 서비스 조건). 모델은 "D일 01~24시" 고정 구조라 날짜 단위로만 예측합니다. 실적·기상이 2026-08-31까지라 예측일은 과거 날짜이고, 그날 실제 발전량·관측 일사량과 겹쳐 비교합니다.

드리프트 시뮬레이션

업로드된 실제 실적에서 21일 구간(+이력 3일)을 잘라 /predict/batch-test로 보냅니다. 서버는 날짜마다 "이력 72시간 + 그날 관측 기상"으로 기대치를 만들어 제도 오차율과 성능비 PR을 기록하고 원인을 분류합니다.
정상 = 삼천포2 최근 21일 · 장마철 = 2026-06-20부터 21일(PR 정상 → 재학습 안 함) · 설비 고장 = 8일째부터 ×0.5(PR 급락 → 알림, 재학습 금지) · 전 발전소 변화 = 3곳 ×1.25(모델 드리프트 → fine-tuning → 게이트 → 재배포).
