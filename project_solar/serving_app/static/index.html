드리프트 시뮬레이션

업로드된 실제 실적에서 35일 구간을 잘라 /predict/batch-test로 전송합니다 (가짜 데이터를 만들지 않습니다). 정상 = 최근 35일 · 장마철 = 2026-06-20부터 35일 · 신규 발전소 편입 = 최근 35일 × 1.8 (학습 범위 밖 → 드리프트). 드리프트가 감지되면 아래 파이프라인이 감지 → fine-tuning → (nRMSE ≤ 8% 통과 시) 재배포까지 진행됩니다.
